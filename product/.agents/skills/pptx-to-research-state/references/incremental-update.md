# 增量导入

从飞书最新版本按 ID/关键词定位并读相关条目。先执行 pptx-evidence.md；复用输入 hash 相同且视觉核验未失效的产物。保留人类编辑、编号、阴性、矛盾和未知参数。

直接观察先进入 CURRENT_STATE；CON 链接实际 OBS 并定级，HYP 明确未验证。新结果影响问题/优先级时改 RESEARCH_QUESTIONS；影响既有路线可行性时改 SOL，但不替换 core_route；用户明确要求新路线才创建 SOL。故事可行性或证据连接受影响时改 PROJECT_STORY。

每次局部写入用当前 revision 和 block ID，结构变化后重新 fetch。日期为可见字段。所有关系用真实飞书链接。按维护技能做一次定向结构校验，普通正文不审计结构。新外部文献执行来源门槛，科学正文执行学术编辑。最终给实际 URL 与受影响研究 ID。
