# 学术写作编辑

优先级：事实/原意与证据边界 → 数字、单位、统计、公式、引用、链接、专名和术语 → 论证结构 → 清楚自然的语言 → 作者及目标语言文风。未获明确要求不增删替换数据和引用，不补实验条件或机制；错误、缺口与矛盾须指出。

## 输入与分支

确定语言、用途、读者和改动幅度，按需读作者样本。审阅仅报告问题和建议；起草、编辑、翻译才改写正文。只授权对话时不创建文档；飞书编辑先按工作流读取最新全文、必要评论及资源，保护原文。

目标故事单独遵循 `.agents/instructions/story-policy.md` 与 story-workflow：仅用户已选路线采用成功完成后的定性摘要，证据缺口集中第六节；不编造数值、统计、条件、引用，不将叙事升格为事实。普通学术正文、投稿和真实汇报仍严格按实际证据表述。

## 编辑

先核对段落功能、证据对应、适用对象/条件/基线/readout、因果关系与指代，再重写。每段一个中心，用具体主语和动词；删无信息的开场、强调和重复，不机械换词或强制短句。保持技术术语一致，翻译可重组句法，不改信息。

主张强度匹配证据：直接测量只覆盖实际对象；相关性、有限样本和单体系不写成因果证明；未验证机制保持假设。显著仅用于有统计依据的结果，比较须有指标/基线/范围。证据不存在时收窄或标待确认，不用流畅文字掩盖问题。

按目标语言读 [language-guide](references/language-guide.md) 的对应部分；不同时强制套用两种语言句法。

## 完成

核对实质信息及必要限定未丢失；数字、公式、单位、引用/图号/链接和术语未改变；无新增事实、因果或机制；语言符合目标读者并覆盖原问题。故事目标摘要与真实支持保持隔离。

交付完整改写文本；仅必要时附短说明和待确认项。飞书更新遵循工作流并回读；审阅不自动改原稿，独立审阅文档仅按用户已授权的交付要求创建。
