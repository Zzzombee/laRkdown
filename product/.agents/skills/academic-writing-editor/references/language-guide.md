# 语言细则

仅阅读目标语言部分。通用原则：保留有用的限定语、定义和技术术语，避免意义拔高、虚假新颖性/因果/显著性、无来源的普遍判断、同义词轮换和刻意口语化；不靠词表机械替换。

## 英文

- 用明确主语和有信息量的动词，减少 there is/are、it is worth noting that、serves as 及无用名词化。
- 一个句子控制主要判断数量；约30词或三层从属只作检查信号，复杂关系表达清楚可保留长句。
- 减少机械的 Moreover/Furthermore/Additionally、无具体依据的 novel/comprehensive/significant/robust/groundbreaking。
- 破折号、冒号和括号只表达必要层次，不堆叠论点。保留自然的 we、hedge 及施事者不重要时的被动语态。
- 按英文句法组织信息，不逐词搬中文分句，不把背景、方法、结果与结论塞进一句。

## 中文

- 指代清楚可承前省主语，主体切换时明确；允许高密度复句，用语序和标点划清层级。
- 优先直接动词，按语义简化“进行了……的分析/研究”；强调过程时可保留名词化。
- 套话、宣传和空泛规模词改成具体问题、条件、指标或证据边界；材料没有数字时不虚构。
- 表明/揭示/证实须有相应证据，有限支持用提示/支持可能性/与……一致。连接词只表达真实关系。
- 该/其/这须有唯一先行对象，必要时重复术语。沿用目标载体的中英文术语、单位、精度与标点，不擅改缩写和数值。
