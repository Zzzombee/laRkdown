# 文献核验与筛选

来源真实性、完整性和主张匹配始终优先，指标不提高证据等级。事实、研究问题、目标叙事和路线分别按项目登记读取，不混淆文献事实与项目事实。

## 选择分支

- 用户以具体引文、DOI/PMID/PMCID 或 PDF 指定论文：只读 [designated-sources](references/designated-sources.md)。主题、作者/期刊名、候选搜索列表不等于指定作品。
- 自主发现/选择文献，或用户明确要求按门槛审计：读 [normal-screening](references/normal-screening.md) 与完整 [screening-policy](references/screening-policy.md)，同任务内复用已读规则。
- 混合任务逐篇分流。缺必要政策仅阻塞相应工作，报告路径，不自拟阈值。

## 共同边界

逐项匹配原文实际实验与主张，区分直接、间接、合理性、冲突和推测。高指标但间接的来源不替代更直接的低指标来源；适用例外按政策记录。

新颖性需说明已有覆盖、剩余材料—体系—刺激—readout 组合和检索范围；未找到不等于不存在，不无界宣称首次/独一。RQ/SOL 任务先读目标问题、直接项目证据和已有路线，保护 core_route 与用户约束。

身份不明、正文不支持、必要指标无法核验且不允许适用警示、或关键参数缺失时，收窄/停止相关主张，明确缺口，不推测补齐。用户指定不免除真实性与证据匹配。
