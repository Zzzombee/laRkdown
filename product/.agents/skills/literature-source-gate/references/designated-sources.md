# 用户指定作品

适用于具体引文、DOI/PMID/PMCID 或用户提供的论文 PDF，仅限被指定作品。主题、作者/期刊名和搜索候选列表不构成指定；额外发现作品另走正常筛选。

使用用户选择的原作品，不自行替换、排名或扩展；另有比较/检索请求时按其范围执行。免除本项目 JCR/JIF、引用年龄门槛、preferred/restricted 分类、例外记录、受限来源警示和指标审计；用户明确要求门槛审计则走正常筛选。

仍核对身份、原始正文/权威记录、撤稿/撤回/完整性问题及句子与实际结果的对应。区分结果、作者解释与推测；保留直接/间接/合理性/冲突/推测标签。发现身份错误、撤稿、无法读取或主张不符时直接说明，不冒充正面证据，也不转成无关的受限指标警示。

指定作品不代表论文证明了主张，单篇也不支持无界新颖性或不存在结论。
