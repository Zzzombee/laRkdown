# 来源筛选政策

用于自主发现/选择的文献及用户明确要求的门槛审计。具体指定作品按 designated-sources，不套指标门槛、引用年龄、分类/例外、受限警示和指标审计；混合任务中的额外作品仍执行本政策。两种分支都保留真实性、完整性与主张匹配。

## 证据排序与排除

优先级：具体主张/实验条件匹配 → 研究设计、报告质量与对照 → 独立重复/汇聚 → 身份和完整性 → JCR/JIF → 年龄调整被引数。指标不将间接证据变成直接结果，也不将作者讨论变成实验事实。

下列不能作为项目事实、机制、安全、可行性或新颖性的正面证据：撤稿/撤回；未解决的关注声明或严重完整性警告；掠夺/劫持期刊、伪造引文、身份不可核验；方法/结果不支持主张；将社论、新闻、营销、审稿/决定信、单独更正或补充记录冒充原始实验；把预印本等非同行评审报告当已确立实验事实；把不兼容材料/细胞/物种/脑区/刺激/readout 拼成同一直接机制。

用户明确讨论诚信、争议、暂定新证据或负面先例时可有界提及，标明状态且不能作正面证据。更正论文须读更正并确认所引结果仍有效。

## 正常门槛

同行评审来源满足一项即通过期刊门槛：相关学科 JCR Q1/Q2；最新可用 JIF ≥5；或公认科学、临床、政府、标准机构的官方指南/共识/证据综合。记录最新可用 JCR 版次、相关学科及查询日期。不将宣传指标、非官方影响因子、CiteScore、SJR 或估算冒充 JCR；改用指标须标明并按本门槛未核验处理。JCR/JIF 均无法验证时为 restricted—期刊指标未核验，不编造数值。

被引数用文章级数据，同一任务尽量用同库：优先 WoS/Scopus，否则 OpenAlex/Semantic Scholar，记录库和日期。

| 发表年龄 | 引用警示 |
| --- | --- |
| 不满2年 | 无最低被引阈值 |
| 2～5年 | 少于5次 |
| 超过5年 | 少于10次 |

不可核验标“被引数未核验”。引用警示或未核验使来源成为 restricted 并适用警示，不证明论文质量差；跨领域比较注明学科/年龄差异。

## 受限例外与警示

通过完整性/主张匹配及正常指标为 preferred；绝对排除者为 excluded；相关但低于或未核验指标/年龄门槛为 restricted。同样直接时用 preferred 替代；无法同等替代且至少满足一项才保留：

- 材料—体系—刺激—readout 最直接匹配；
- 不可替代的实验/方法细节；
- 领域经典、标准方法或原始描述；
- 新近且必须覆盖的先例，尚未积累引用；
- 窄领域系统性较低指标；
- 避免偏倚所必需的阴性、冲突、安全或边界结果；
- 用户明确要求该来源且未要求隐瞒限制。

记录无同等直接优选来源、确切理由、有界主张及独立佐证。受限来源不能单独支持无条件的强因果、机制、安全、临床成熟或新颖性判断；唯一证据时将结论标暂定并写明缺少的确认。

首次实质使用时在飞书正文放可见 warning callout 或链接到文内核验区，含作者/年份、未达或未核验项、指标来源/版本/日期、保留理由、支持/不支持什么及佐证。当前官方 DocxXML 示例：

```xml
<callout emoji="⚠️" background-color="light-yellow"><p><b>受限来源</b></p><p>作者（年份）：门槛及指标来源/版本/查询日期；保留理由；支持边界；独立佐证。</p></callout>
```

对话用简短可见警示；投稿稿件可脚注/局限性并在交付记录保留决策，不能静默去掉整份产物的警示。内部台账同样保留信息，不依赖专有 Markdown callout。

## 检索与原文核验

生物医学从 PubMed/PMC、OpenAlex、Crossref、Semantic Scholar 发现；OpenReview 仅用户明确请求才用。全局 paper-search/paper_search 及 search_papers.py 暂禁，只有用户明确重启才可调用。

决定性事实优先原文、PubMed/PMC、期刊/出版社或 DOI 页面。Crossref 主要核对身份/DOI，筛掉补充材料、审稿/决定信、单独更正和关键词误匹配。Semantic Scholar 429 仅按当前工具作一次有限重试周期，仍失败换来源，同任务不重复相同查询。摘要片段、引用图谱和自动总结只作发现辅助，不能代替原文。

核验题目、作者、年份、类型、期刊与稳定标识；检查撤稿/撤回、关注声明、更正；逐句对照实验与结果，区分讨论和推测。每篇关键作品记录材料、物种/体系、疾病模型、脑区/回路、刺激方式/时序、readout、随访、来源角色和直接性，未知不由相邻论文补齐。

证据标签：direct support（条件/结果直接匹配）；indirect support（关键条件有差异）；plausibility/is consistent with（仅支持合理性）；conflicting/boundary（限制或矛盾）；speculation（未建立解释）。间接/合理性不得写成直接证明。

## 引文与最终核对

飞书正文以作者—年份为可点击标签，优先真实 DOI，其次稳定期刊/出版社 URL，紧邻主张；参考区复用短引文并标关键证据/边界，同作者同年消歧。例：`<a href="https://doi.org/实际DOI">作者, 年份</a>`。

项目内链接用登记的真实文档及最新块，标签保留研究 ID，不用专有笔记链接或假定反链。内部文件/脚本/台账保留纯路径、DOI、URL、ID，不拿显示标签作资源身份；文献与科研事实分开。

交付前确认：身份与完整性已核验；原文支持确切主张；不跨体系拼因果；指标版次/学科/库/日期齐备；每个受限来源有例外和可见警示；排除来源不作正面证据；未找到/新颖性不超过记录的检索范围。
