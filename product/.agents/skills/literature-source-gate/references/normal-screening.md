# 自主检索与门槛审计

先完整读取 screening-policy.md；该文件唯一维护阈值、排除、例外、数据库/重试、证据标签和引文格式。本流程不另设门槛。同一任务未变的政策不重复读取。

1. 定义需要支持的具体主张和来源角色：核心实验/因果/机制/安全/新颖性，背景合理性，方法/定义/指南，或阴性/冲突/风险。
2. 记录检索日期、范围/时间窗、数据库、材料/器件、体系/模型、刺激、readout 和随访；按请求适用的窗口检索，元数据仅作发现线索。
3. 对实质影响判断的作品核验身份、类型、DOI、完整性状态和原始实验；按政策记录条件匹配与证据直接性，缺字段标未知。
4. 按政策分 excluded/preferred/restricted；同样直接时优选通过门槛的来源。必要例外记录理由、主张边界、独立佐证和可见警示，不能放宽证据来维持预设路线。
5. 将引文紧邻主张，文档与对话使用政策显示格式；内部路径/DOI/URL/ID 保持字面值。
6. 交付前核对作品身份、主张对应、指标版本/来源/日期、例外和警示，排除不合格正面证据，新颖性不超检索范围。不要把文献核验和纯项目内容问答混在一起。
