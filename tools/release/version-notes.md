# laRkdown 版本说明（v0.2.6）

待发布。相较 v0.2.5，本次将个人科研预设与开发维护彻底分离。

- 节省用户 token 列为高优先级：一次下载、一次升级执行，确定性校验交给脚本，默认短回执；日常按任务读取内容和检查环境。
- 根目录 AGENTS.md 只管理本地开发、测试和发布；product/AGENTS.md 只管理豆包与飞书个人科研工作。
- 科研包保留五个科研技能。升级技能、版本说明、来源版本及升级基线移到发行 ZIP 内与科研目录并列的 maintenance/；科研入口不再承担版本管理。
- 科研包按 product/ 白名单映射构建。构建与测试同时检查路径、内容、哈希和实际 ZIP 成员，阻止开发指令重新混入。
- 独立升级器支持历史安装迁移，移除未修改的旧维护入口，保护人工增补、私人登记、原始资料和同步基线；修改过的相关文件报告冲突。

日常科研仍通过豆包直接记录实验、导入 PPTX、编辑学术正文、核验文献、生成项目故事或构建和同步知识库多维表格。维护操作使用同一个 ZIP 内的 maintenance/ 工具，不在科研项目内加载。

本版本未改变科研事实来源或远端飞书资源。结构提取通过仍不代表完成图片视觉核验；不宣称用户环境已具备渲染或识图能力。
