# laRkdown 版本说明（v0.3.0）

相较 v0.2.5，本版隔离个人科研与开发维护内容，并共同优化首次环境准备和模型指令开销。

- 同一 ZIP 内保持 laRkdown/ 科研目录和 maintenance/ 工具目录。新环境入口复用已通过检查的 Python/官方 CLI，缺失时准备用户级固定组件；不要求预装 Python/Node，不修改系统 PATH 或用户包。
- 基础路径跳过 pip、PPTX 依赖和渲染器检查；Base 按需检查额外接口，PPTX 用隔离环境和含传递依赖/哈希的固定 wheel 清单。中断保留状态，重跑续装。
- 科研目录新增 run.py/run.ps1，显式使用本机选中的解释器与 CLI，处理多 Python、旧 PATH 和 npm 启动器；不把版本号较旧等同于不兼容。
- 精简 AGENTS 与五技能入口，故事/文献/语言规则分层并合并重复；常见任务按需加载，正常短回执。科研证据、稳定编号、目标叙事隔离、来源门槛、写后回读、冲突/pending 恢复保留。
- 本次维护的指令与指南计入新增参考后，字符量约减少 42%；这是文本规模对比，不是豆包 token 或实际安装耗时测量。
- 发行分发合同更新为 schema 4，兼容读取 schema 3 维护包；产品 schema 仍为 1。安装资源及第三方许可只在维护目录，历史发行基线和已发布 tag 不改写。

仍保留原有隔离：开发根 AGENTS 不路由科研技能；product/ 是科研包唯一来源。升级仅管理核验路径，保护用户编辑、飞书登记、原始资料和同步基线，日常不触发发行校验。

安装只检查软件和本地帮助，不访问真实飞书。CLI 版本/帮助检查不证明实际用户授权、远端冲突或客户端完整兼容；不宣称豆包预装运行时。PPTX 提取不替代整页渲染和实际看图；实际安装耗时与 token 收益仍需用户环境测量。
