# 学术写作编辑

使学术文本准确、清楚、紧凑并适合目标语言。以证据和含义为边界，不以“像人写的”为理由增加个性、修辞或未经支持的判断，也不用于规避 AI 使用披露。

## 核心优先级

按以下顺序处理冲突：

1. 保持事实、证据边界和作者原意；
2. 保持数字、单位、统计结果、公式、引用、链接、专名和技术术语；
3. 建立清楚的论证结构和指代关系；
4. 提高句段可读性与语言自然度；
5. 匹配作者已有文风和目标语言习惯。

除非用户明确要求核实或改动，不新增、删除或替换数据与引用，不补造实验条件、证据指针或机制解释。发现原文可能有事实错误、引用缺口或内部矛盾时，标出问题，不用流畅措辞掩盖它。

## 工作流程

### 1. 确定编辑边界

- 判断目标语言、文本用途、读者知识水平和用户要求的改动幅度。
- 优先读取作者提供的写作样本；记录其术语选择、句子节奏、段落推进、限定语和常用表达，但不模仿其中的含混或证据越界。
- 识别哪些内容是直接结果、解释、假设、背景知识和目标性主张。项目已有的事实来源和证据规则始终优先。
- 用户要求审阅或诊断时，只报告问题和建议；用户要求起草、改写、润色或翻译时，才改写正文。
- 项目目标故事的摘要式故事遵循 `.agents/instructions/story-policy.md` 与故事工作流：按体系已经完成并正式发表的完整成功结果编辑，证据链不足处按用户已选故事补齐定性结果关系，不改回“预期”“拟”“如果成功”等计划语气，也不在摘要中加入证据缺口。实际证据、阴性、矛盾及成立条件集中在故事第六节。该叙事规则不适用于实际投稿、真实实验汇报或状态条目，不授权编造数值、样本量、统计、参数或引用。

### 2. 先审计内容，再调整语言

逐段检查：

- 本段是否有单一且明确的论证功能；
- 每个经验性主张是否有数据、图表、统计结果、项目内证据或外部文献支撑；
- 主张的适用对象、条件、时间范围、比较基线和 readout 是否清楚；
- 动词强度是否与证据相称；
- 前后句是否存在真实的因果、转折、递进或并列关系；
- 同一术语是否被不必要地换成近义词；
- 删除一句后信息是否完全不变。若不变，该句通常是填充语或重复。

不要仅凭词表机械替换。先判断词语在具体句子中的论证功能，再决定保留、删除或重写。

目标故事摘要在此步骤核对成功叙事的完整性与所选路线的一致性，不因实际证据缺口删去成功结果或改为计划语气；其真实证据对应关系与限制在故事第六节核对。

### 3. 重写

- 每段围绕一个中心推进，通常按“问题或对象 → 证据或分析 → 有边界的判断”组织。
- 让关键主语、动作、比较和结论尽早出现；减少多层插入语和连续从句。
- 用具体对象、条件、指标、数量或范围替代“显著提升”“大量”“广泛”“多种”等空泛说法；原文没有相应信息时，收窄或标记缺口，不虚构数字。
- 删除没有论证作用的开场、总结、强调词和机械连接词，例如“值得注意的是”“毋庸置疑”“近年来受到广泛关注”。
- 删除宣传性、绝对化或装饰性措辞，例如“突破性”“革命性”“至关重要”“丰富图景”；改为可检验的问题、差异或限制。
- 避免为了节奏强行凑三项、使用“不仅……而且……”式虚假升级，或反复换词指称同一对象。
- 保留必要的限定语、被动语态、第一人称复数、正式定义、符号和技术术语。
- 翻译时保持信息和证据不变，但按目标语言重组句法与信息顺序；不要逐句保留源语言结构。

### 4. 核对证据与措辞

以下规则适用于实际证据陈述与普通学术正文；目标故事摘要采用第 1 步明确的正式论文式成功叙事规则。对故事的证据等级与未建立状态，在第六节核对，不逐句将摘要降为计划或条件句。

- 直接测量可以写为“观察到”“测得”“结果显示”，但只覆盖实际测量的对象与条件。
- 相关性、有限样本或单一体系通常只能写为“支持”“提示”“与……一致”，不能自动写成“证明”“确立”或机制因果。
- 未经验证的机制保持为“可能”“假设”“有待检验”。不要为了让句子更有力而删除合理限定。
- “显著”仅用于已有明确统计含义的结果；否则改用具体效应或中性比较。
- 比较结论应注明指标、对照或基线及适用范围。不能从局部结果推出普遍优越性。
- 找不到证据指针时，优先使用已有材料补上；若材料中不存在，则收窄主张或明确标记待作者确认。

## 英文学术写作

英文依靠显式主谓结构和清楚的句间逻辑。编辑英文时：

- 优先使用明确的主语和有信息量的动词，减少 `there is/are`、`it is worth noting that`、`serves as` 以及不必要的名词化结构。
- 控制一个句子中的主要判断数量。约 30 个词或包含三层以上从属关系只是检查信号，不是强制断句标准；能清楚表达单一复杂关系的长句可以保留。
- 避免连续使用 `Moreover`、`Furthermore`、`Additionally` 等句首连接词。让语义关系或段落结构承担衔接。
- 避免空泛的 `novel`、`comprehensive`、`significant`、`robust`、`groundbreaking` 等词；用具体贡献、范围、检验或结果替代。
- 谨慎使用破折号、冒号和括号。它们可以保留，但不能用来堆叠原本应拆开的论点。
- 保留学术英语中自然且准确的 `we`、证据性 hedge 和在施事者不重要时的被动语态，不要为了追求主动语态而扭曲重点。
- 避免中文句法的逐词迁移，例如连续的 “under the condition of”、无明确主语的长串分句，或把背景、方法、结果和结论塞入同一句。

## 中文学术写作

中文依靠主题推进、语序和上下文形成连贯性，不能套用英文的表面句法。编辑中文时：

- 在指代清楚时允许承前省略主语，不机械地为每句补入“我们”或研究对象；出现主体切换时再明确主语。
- 不把“短句越多越清楚”当成规则。可以保留信息密度较高的复句，但要用分号、冒号或分句顺序明确层级，避免一个句号内并列过多判断。
- 优先使用直接动词，例如把“进行了……的分析/研究/探讨”按语义改为“分析/研究/检验……”，但在强调过程或研究范围时可以保留名词化表达。
- 减少套话和公文式表达，例如“随着……的不断发展”“具有重要的理论意义和现实意义”“起到了至关重要的作用”；改写为具体问题、影响或证据边界。
- 谨慎使用“表明”“说明”“揭示”“证实”。它们常比英文 `suggest` 或 `is consistent with` 更确定；证据有限时使用“提示”“支持……的可能性”“与……一致”。
- 不机械添加“此外”“同时”“因此”“然而”。只有逻辑关系真实且仅靠语序不足以辨认时才使用连接词。
- 让“该”“其”“这”“上述”等指代有唯一先行对象；连续出现多个候选对象时直接重复术语，以准确优先于避免重复。
- 中英文术语、数字、单位与标点遵循项目或目标载体的既有格式。不要以中文润色为由翻译固定术语、改变缩写或调整数值精度。

## 常见问题清单

重点识别并按语境处理：

- 无具体内容的意义拔高、趋势开场和结尾展望；
- 没有证据的因果、普遍性、新颖性或显著性主张；
- 句尾附加现在分词或抽象总结，却没有增加可验证信息；
- 含糊来源，如“研究者普遍认为”“已有大量研究表明”而无适当引用；
- 同义词轮换导致技术对象不稳定；
- 多段重复同一背景、结论或限制；
- 一句话堆叠背景、方法、结果、解释和意义；
- 为显得自然而加入意见、比喻、幽默、情绪或口语化评价。

## 完成前验证

逐项确认：

1. 原文的实质信息均被保留，除非用户明确要求删减或重组；
2. 数字、单位、统计结果、公式、图表编号、引用、链接和专名未被意外改变；
3. 实际证据陈述没有新增材料中不存在的事实、证据、机制或因果关系；目标故事摘要中的成功结果补齐仅限用户已选故事，不混入事实层；
4. 实际证据主张的强度与证据相称，必要的限定语仍然存在；目标故事摘要保持完整成功结果性语言，其真实支持程度与限制在第六节保留；
5. 同一技术对象使用一致术语，代词和指示词有清楚指向；
6. 中文符合中文的信息组织习惯，英文符合英文的句法与衔接习惯；
7. 改写后的文本仍覆盖原文需要回答的问题。

交付完整的修改后文本。仅在有助于用户复核或用户要求时，附上简短修改说明，列明结构调整、被收窄的主张和需要作者确认的缺口。
