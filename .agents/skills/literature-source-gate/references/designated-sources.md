# User-designated sources

Use this mode when the user explicitly selects one or more identifiable works by providing a concrete bibliographic citation or stable index such as a DOI, PMID, or PMCID, or by supplying the article PDF. Apply it only to the designated works. A topic, author name, journal name, search result list, or request to “find relevant papers” is not a designated work.

For each designated work:

1. use the exact source the user selected; do not search for replacements, rank it against alternatives, or apply candidate-selection criteria unless the user separately asks for comparison or discovery;
2. skip the default JCR/JIF gate, citation-age threshold, preferred/restricted classification, exception record, restricted-source warning, and metric audit;
3. verify bibliographic identity and inspect the supplied PDF or authoritative article record when available;
4. retain the non-waivable integrity and evidence checks: do not silently present a retracted, withdrawn, fabricated, misidentified, or claim-mismatched source as positive evidence;
5. match each consequential statement to what the article actually reports, distinguish results from author interpretation, and preserve direct, indirect, plausibility, conflicting, or speculative evidence labels;
6. report any material integrity problem, inaccessible evidence, or claim mismatch directly and narrowly, without converting it into the policy's restricted-source warning.

The user's designation authorizes use of that source without the project's metric gate; it does not establish that the paper proves a claim. A designated paper alone also cannot support an unbounded novelty or absence claim. If the user explicitly asks to audit the designated source against the project gate, use the normal screening mode instead.

For mixed tasks, keep the routes separate: designated works use this mode, while any additional literature discovered or selected by 豆包工作 uses normal screening mode.
