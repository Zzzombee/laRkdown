# 六表与来源

六表沿用既有表名；源知识库文档是唯一事实层。脚本按原生标题划分条目。所有表的阅读字段至少包含“概要”“原文”“引用”：概要来自去编号的源标题或任务首句，可在 selector 中提供经核对的中文标题；原文保留条目正文的可读文字，去掉重复编号和来源、状态、证据等级、引用等已经分列的独立元数据行；引用从已有链接、DOI 或显式引文行提取。图片、公式与附件仅给出查看源文档的提示，不把资源 token 当正文。原始 XML 快照仍保存在忽略目录。

| 表 | 默认来源与同步键 | 写入内容 |
| --- | --- | --- |
| 项目概览 | CURRENT_STATE 非研究条目的正文小节、PROJECT_STORY 小节；文档 key + 标题路径 | 概要、原文、引用；旧条目和内容列保留供兼容 |
| 实验观察OBS | CURRENT_STATE；OBS-### | 概要、编号、原文、引用 |
| 结论与假设 | CURRENT_STATE；CON/HYP-### | 概要、编号、源类型、源证据等级、原文、引用、依据 |
| 研究问题RQ | RESEARCH_QUESTIONS；RQ-### | 概要、编号、原文、引用、显式状态、优先级 |
| 关键参考文献 | PROJECT_STORY 中 DOI/文献段落的外部链接；DOI 优先、否则规范化 URL | 概要、原文、引用、文献、链接、展示序号 |
| 近期优先事项 | 三文档中明确标题为“近期优先事项/近期优先实验/近期任务/下一步”的小节；显式 TASK-### 优先、否则全文 hash | 概要、原文、引用、提及关系、展示序号 |

共同技术字段：同步键、同步项目、来源文档、来源链接、来源版本、源内容哈希、来源语义、关联编号。它们在“科研阅读”视图中隐藏，但仍保留以识别增量、定位源块、检查冲突与归档；不能删除。归档状态保留可见。源内容哈希不含读取时间/版本，因此正文未变的条目不会随整篇版本变动反复更新。来源版本表示最后一次该行内容同步时使用的版本。接入已有 Base 时创建新阅读视图，不改已有视图；旧表的主字段可能仍由平台强制显示。

标题前的可见说明和范围保留为“文档说明”概览条目。未展开的同步引用和局部 excerpt 不满足完整提取条件，须读取真正的内容来源后适配，不能据此归档原条目。

“来源语义”区分科研状态摘录、研究问题原文、目标论文叙事、原文引文与原文任务。Story 的第5节是“本项目的独特基础”，不能照旧手册当文献目录。引用条目只搬运原有定位，链接去重不代表文献真实性已重新核验。

源证据等级只提取显式“证据等级/证据强度”字段，保留原文；无明确标签时留空并保留正文，不从主张强弱推断。源类型直接取稳定编号 CON/HYP。旧模板“证据强度”列选项不覆盖全部原生等级，保持原列不写，新增文本列“源证据等级”。旧 AI“类型”列保持不写。优先级取显式“优先级：P1…P5/暂缓”，或父标题“P1/优先级 1”等；“已解决或暂缓”这种混合标题不能推断单条状态或优先级。

关系使用真实 Record ID 的单向关联字段：结论与假设 → OBS/RQ；RQ → OBS/结论与假设；近期事项 → RQ。关联含义是**原文提及**，不自动等同于支持、因果或方案归属。所有提及编号另存“关联编号”；尚未导入的目标保留编号并报告，不生成假 Record ID。关系在六表基础记录创建后第二阶段写入。

## 非标准文档

配置 `selectors[文档key][真实block-id]` 可指定 `role`、`key`、`title`，不改源文档。`title` 用作阅读视图概要时须忠于原条目，可由 Agent 起草中文短句并核对，不增添新事实。支持 role：`entry`（key 必须为对应 OBS/CON/HYP/RQ 编号）、`overview`、`task`、`references`、`ignore`。标题块从该标题至下一个同级或上级标题；普通块只选该块，不能推测后续范围。非编号科研条目先显式选择，稳定编号禁止由脚本分配；`ignore` 只排除被用户确认不是条目的纯索引或说明。

概览标题或无 TASK 编号的任务正文变化，会形成新身份并归档原记录；需要长期保留同一任务身份时在 selectors 里给固定 key，或在来源正文使用 TASK 编号。空白未填写的小节不生成假内容。项目概览不是科学摘要，不把目标叙事当已验证 CON。

## 接入旧表

支持用户提供的**空白副本**，添加缺少的专用字段并保留旧字段、视图和 AI 设置。已有表中不带本技能同步项目/同步键的记录不自动接管；若业务编号撞车，停止并列出冲突。迁移需要单独明确对应关系和预览，不能按旧序号盲目覆盖。源登记换成另一组文档时使用新的知识库多维表格与本机配置，不复用既有同步身份。
