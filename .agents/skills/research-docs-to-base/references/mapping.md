# 六表与来源

默认六表沿用旧工作台名称；源文档是唯一事实层。脚本按原生标题划分条目，保留段落/列表/表格的文字、真实链接及资源标记。原始 XML 快照仍保存在忽略目录，表格不复制正文中的全部媒体。

| 表 | 默认来源与同步键 | 写入内容 |
| --- | --- | --- |
| 项目概览 | CURRENT_STATE 非研究条目的正文小节、PROJECT_STORY 小节；文档 key + 标题路径 | 条目、内容、来源语义 |
| 实验观察OBS | CURRENT_STATE；OBS-### | 编号、标题、原文 |
| 结论与假设 | CURRENT_STATE；CON/HYP-### | 编号、内容、原文、依据、源类型、源证据等级 |
| 研究问题RQ | RESEARCH_QUESTIONS；RQ-### | 编号、问题、原文、显式状态、优先级 |
| 关键参考文献 | PROJECT_STORY 中 DOI/文献段落的外部链接；DOI 优先、否则规范化 URL | 文献链接文字、链接、定位与边界原段落、展示序号 |
| 近期优先事项 | 三文档中明确标题为“近期优先事项/近期优先实验/近期任务/下一步”的小节；显式 TASK-### 优先、否则全文 hash | 优先事项原文、提及编号、展示序号 |

共同字段：同步键、同步项目、来源文档、来源链接、来源版本、源内容哈希、归档、关联编号。源内容哈希不含读取时间/版本，因此正文未变的条目不会随整篇版本变动反复更新。来源版本表示最后一次该行内容同步时使用的版本。

标题前的可见说明和范围保留为“文档说明”概览条目。未展开的同步引用和局部 excerpt 不满足完整提取条件，须读取真正的内容来源后适配，不能据此归档原条目。

“来源语义”区分科研状态摘录、研究问题原文、目标论文叙事、原文引文与原文任务。Story 的第5节是“本项目的独特基础”，不能照旧手册当文献目录。引用条目只搬运原有定位，链接去重不代表文献真实性已重新核验。

源证据等级只提取显式“证据等级/证据强度”字段，保留原文；无明确标签时留空并保留正文，不从主张强弱推断。源类型直接取稳定编号 CON/HYP。旧模板“证据强度”列选项不覆盖全部原生等级，保持原列不写，新增文本列“源证据等级”。旧 AI“类型”列保持不写。优先级取显式“优先级：P1…P5/暂缓”，或父标题“P1/优先级 1”等；“已解决或暂缓”这种混合标题不能推断单条状态或优先级。

关系使用真实 Record ID 的单向关联字段：结论与假设 → OBS/RQ；RQ → OBS/结论与假设；近期事项 → RQ。关联含义是**原文提及**，不自动等同于支持、因果或方案归属。所有提及编号另存“关联编号”；尚未导入的目标保留编号并报告，不生成假 Record ID。关系在六表基础记录创建后第二阶段写入。

## 非标准文档

配置 `selectors[文档key][真实block-id]` 可指定 `role`、`key`、`title`，不改源文档。支持 role：`entry`（key 必须为对应 OBS/CON/HYP/RQ 编号）、`overview`、`task`、`references`、`ignore`。标题块从该标题至下一个同级或上级标题；普通块只选该块，不能推测后续范围。非编号科研条目先显式选择，稳定编号禁止由脚本分配；`ignore` 只排除被用户确认不是条目的纯索引或说明。

概览标题或无 TASK 编号的任务正文变化，会形成新身份并归档原记录；需要长期保留同一任务身份时在 selectors 里给固定 key，或在来源正文使用 TASK 编号。空白未填写的小节不生成假内容。项目概览不是科学摘要，不把目标叙事当已验证 CON。

## 接入旧表

支持用户提供的**空白副本**，添加缺少的专用字段并保留旧字段、视图和 AI 设置。已有表中不带本技能同步项目/同步键的记录不自动接管；若业务编号撞车，停止并列出冲突。迁移需要单独明确对应关系和预览，不能按旧序号盲目覆盖。源登记换成另一组文档时使用新工作台与新本机配置，不复用既有同步身份。
